A native Windows disk explorer that turns a whole NTFS drive into an interactive map. Find large files, explore file types, search, and compare saved scans.

Early preview · Windows x64 · NTFS · Administrator required

Windows 10/11 x64. Unsigned build: Windows may show an unknown-publisher warning. Extract the ZIP, open Diskvale.exe, then choose a drive and click Scan. No development tools needed.

The NTFS reader is experimental. Unsupported or incomplete metadata returns an error; large scans can require substantial memory. Full-volume correctness and performance parity have not been established. Deletion uses best-effort identity checks and explicit confirmation.
