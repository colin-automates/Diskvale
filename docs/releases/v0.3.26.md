# Diskvale 0.3.26 — Early preview

This preview fixes the live NTFS scan rejection reported in 0.3.24 and includes a fully validated retry for inconsistent parent references. The user confirmed a full scan of the original failing C: drive on the 0.3.26 candidate, followed by working Map, Files, Types, search, snapshot save/reopen and CSV export.

## Changes since 0.3.24

- Resolve supported nonresident `$ATTRIBUTE_LIST` data for the MFT and ordinary files/directories. The old bulk reader rejected layouts already understood during MFT bootstrap. The connected volume/bootstrap/bulk/tree regression failed before the repair and now passes with the expected totals.
- Validate complete listed attribute identities, extension ownership and bootstrap/bulk consistency. Bounded, sector-compatible external reads preserve the sequential reader's cursor and support fragmented storage. Missing or unsupported metadata still prevents a complete-looking result.
- Retry the entire live index once after a typed directory/file parent-reference failure. The retry reads fresh geometry/bootstrap metadata and repeats all validation. A persistent failure reports numeric record/sequence identities without filenames. Cancellation and unrelated invalid metadata do not trigger another read.
- Update the README, download page and compatibility notes for this preview. Existing branding, interface, dependencies, size accounting and deletion safeguards are retained. The 0.3.25 test candidate remains unpublished; older published tags and assets are unchanged.

## Validation and limits

Formatting, locked tests (**139 library + 7 integration tests passed; 3 opt-in tests ignored**) and strict all-target Clippy passed. The 44 MFT regressions cover volume-backed list resolution, fragmented/tail reads, wrong or missing identities, changing bootstrap metadata, cursor restoration, duplicate merging, cancellation, saved-result restrictions and complete parent-reference retries. The ignored Shell-deletion integrations were not enabled for this scanner repair.

The live C: scan and application smoke checks above were **user-confirmed** on the candidate built from `054372fb9514113a0846154c19e37e2dfbb7ee96`, with EXE SHA-256 `1b201b90c6811717d4506455ac3273e4a293f047a9422a57a0937142ba14eb72`. The public package is rebuilt from the clean release commit containing the same application code plus final release documentation. `BUILD_INFO.json` records that package's source, toolchain and EXE checksum. No private drive captures or filenames were uploaded. The original C: parent mismatch's exact cause was not established.

**Windows 10/11 x64, whole-drive NTFS and administrator access are required.** This unsigned build may show an unknown-publisher warning. The reader remains experimental; scans are live metadata reads, not atomic snapshots, and large scans can require substantial memory. Full-volume correctness and performance parity with other tools have not been established.

Split list mappings, compressed/sparse/encrypted lists and other unsupported or inconsistent metadata remain explicit errors. Flat saved-MFT files cannot supply missing external list clusters and never fetch them from a live drive. Snapshot format and compatibility are unchanged from 0.3.24. Saved, partial and stale results cannot authorize deletion. Deletion retains best-effort identity checks and explicit confirmation; it is not atomic or race-free. See [technical details](../technical.md), [attribute-list regressions](../ntfs-list-test-candidate.md) and [same-drive acceptance](../ntfs-parent-test-candidate.md).
